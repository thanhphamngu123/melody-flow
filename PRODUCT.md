# Product

## Platform

web

## Users
Music lovers, friend groups, long-distance couples, gamers, and study groups listening to YouTube music together in real time.

## Product Purpose
MelodyFlow enables synchronized YouTube music playback rooms with zero latency (<0.05s), live chat, and GIF reactions without registration.

## Positioning
Realtime WebSocket YouTube Audio Sync Engine with instant 5-character private room code access.

## Capabilities and Constraints
- Realtime YouTube sync (<0.05s latency)
- Instant room creation with 5-character code
- Batch YouTube search and add
- Live chat and Giphy GIF stickers
- Reusable Web Audio synth pad ambient player
- 100% free with no registration required
